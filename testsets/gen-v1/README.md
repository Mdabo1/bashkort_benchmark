# gen-v1

56 заданий на русском с просьбой ответить по-башкирски. Семь категорий: `everyday`, `kids`, `letters`, `creative`, `knowledge`, `rewrite`, `grammar`. Задания написаны для бенчмарка, лицензия MIT вместе с кодом.

Автоматически проверяются только грубые провалы: язык ответа, чужие буквы, слова вне словаря. Качество оценивают носители по `human_eval/GUIDELINES_RATING.md`.
